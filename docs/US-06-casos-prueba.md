# US-06 · Casos de creación y consulta de salas

20 de noviembre de 2026 (America/Bogota) · Rama `feature/US-06-crear-salas` · [Informe QA](US-06-informe-QA.md)

«Dado» identifica las precondiciones, «Cuando» los pasos, y «Entonces» el resultado esperado. **PASA** indica ejecución local conforme. **PENDIENTE** identifica una comprobación por ejecutar. **NO APLICA** identifica un caso fuera del alcance de este backend.

## Pruebas automatizadas locales

Express y Swagger se prueban mediante HTTP local. Firebase Auth y Firestore se sustituyen por dobles. La comprobación del listado usa el adaptador real sobre un cliente simulado.
